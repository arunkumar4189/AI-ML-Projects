# How to fill your Upwork profile

Official references:

- [Profile title and overview](https://support.upwork.com/hc/en-us/articles/34925678839827-Your-profile-title-and-overview) — title **70** characters; overview **5,000**; search preview shows about the **first 250**
- [Enhance your profile / portfolio](https://support.upwork.com/hc/en-us/articles/360016144974-How-to-enhance-your-freelancer-profile) — portfolio title **70**, role **100**, description **600**, **five** skill tags
- [Portfolio guide](https://www.upwork.com/resources/portfolio-guide)

## 1. Photo, location, rate

- Professional headshot (same one as OpenTrain is fine)
- Location: Chennai, India
- **Hourly rate:** set it yourself. For this positioning (production agents + senior architecture, not cheap labeling), a defensible start is **$50–$80/hr**. Drop toward **$40** only if you need the first three reviews; raise after Job Success Score exists.
- Availability: part-time unless you are actually taking 30+ hrs/week

## 2. Title and overview

Profile Settings → **Title** and **Overview**. Paste from `PROFILE_COPY_PASTE.md`. The first two sentences are the search snippet — do not lead with education.

## 3. Skills (max 20)

Add all twenty from `PROFILE_COPY_PASTE.md`. Upwork matching uses these heavily. Prefer the platform’s autocomplete labels when they appear (e.g. type `LangChain` and pick the official tag).

## 4. Employment

Add Verizon, Tech Mahindra, and Wipro with the blurbs in `PROFILE_COPY_PASTE.md`. Keep titles identical to the career resume so they do not contradict LinkedIn.

## 5. Education

- M.Tech AI & ML, BITS Pilani, 2025–2027 (expected)
- B.E. CSE, Anna University, 2010

## 6. Other experiences (optional)

Paste the M.Tech “other experience” block. Useful because coursework is not an employer.

## 7. Portfolio (six items)

Profile → Portfolio → **+**

For each card in `PORTFOLIO_ITEMS.md`:

1. Title, role, description, five skills
2. **Link:** GitHub file/folder URL for coursework items
3. **Media:** screenshot of a notebook figure, architecture diagram, or metrics table (export from the `.ipynb` HTML). Recommended image size **1000×750**.
4. Production Verizon work: **no internal screenshots, no customer data**. Text-only card is enough; clients hire the judgment, not the VPN screenshot.
5. Publish. Drafts are not visible.

Do **not** put email, phone, WhatsApp, or LinkedIn in titles, descriptions, images, or linked pages. Upwork rejects contact details in portfolios.

## 8. Project Catalog (optional)

If you want inbound “Buy a project” leads, publish **two or three** gigs from `PROJECT_CATALOG.md` — not all five. Catalog spam looks inexperienced.

## 9. Proposals

Use `PROPOSALS.md`. Keep first proposals **150–250 words**. Name the client’s stack, propose a 3-step plan, point at one portfolio card, end with one question.
