# OpenTrain AI profile pack

Copy-paste material to complete an [OpenTrain AI](https://www.opentrain.ai/docs/trainers/profile-setup/) trainer profile from:

- This GitHub repo: [arunkumar4189/AI-ML-Projects](https://github.com/arunkumar4189/AI-ML-Projects)
- The attached professional resume (Verizon Distinguished Engineer; M.Tech AI & ML, BITS Pilani)

OpenTrain matching is driven by **labeling / AI-training experience**, skills, languages, and a short public title — not only a software-engineering CV. This folder translates M.Tech implementations into that taxonomy.

## How to use it

1. Create or open your account → **Settings → Profile**.
2. Upload a **general resume** (your existing Distinguished Engineer CV as PDF/DOCX).
3. Optionally upload **`AI_Training_Resume.txt`** (or the generated DOCX) as the **data labeling / AI training resume**.
4. Paste fields from [`PROFILE.md`](PROFILE.md) into the wizard (overview, title, industries, skills, languages, education, work history).
5. Add each **labeling experience** row from [`PROFILE.md`](PROFILE.md#labeling-experience-entries).
6. Keep [`PORTFOLIO_PROJECTS.md`](PORTFOLIO_PROJECTS.md) as the public GitHub evidence employers can open.

Do **not** list Scale AI, Labelbox, CVAT, Appen, or similar unless you have actually used them. Employers filter on those tools; false entries hurt credibility.

## Suggested positioning

You have **15+ years of production software** and **current M.Tech + Verizon GenAI** work. For OpenTrain’s *AI training* experience slider, **Intermediate (1–3 years)** is the honest band: domain evaluation, SFT/QLoRA, classification, NER-style extraction, and LLM-as-judge style verification from coursework and enterprise GenAI — not a decade of marketplace annotation.
